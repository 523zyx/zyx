number

数值型 number

表示整数或小数（如 2026、3.14），可进行算术运算。

var y1_num = 2026;
typeof → "number"
string

字符串型 string

用单引号或双引号包裹的一串文本。

var y1_str = "周雨欣";
typeof → "string"
boolean

布尔型 boolean

只有 true（真）和 false（假）两个值，常用于条件判断。

var y1_bool = true;
typeof → "boolean"
undefined

未定义型 undefined

变量声明后未赋值时，它的类型就是 undefined。

var y1_und;
typeof → "undefined"
object

空型 null

表示"空值"。typeof 检测结果为 object，属于历史遗留的特殊情况。

var y1_nul = null;
typeof → "object"
object

对象型 object

由键值对组成的复合数据，typeof 检测结果为 object。

var y1_obj = { y1_name: "周雨欣" };
typeof → "object"
