JavaScript 对象

对象是"键值对的集合"，像一排贴了标签的抽屉。点击按钮，看数据是怎么被存取、增删的。

对象长什么样

object

用花括号包起来的一堆 key: value，key 是标签，value 是东西。取值用 对象.属性 或 对象["属性"]。

var student = { ... }
var student = { name: "周雨欣", age: 20, major: "信息管理" }; student.name // 点语法 student["name"] // 方括号语法

属性 与 方法

property / method

属性是"数据"（静态的值），方法是"动作"（值为函数的属性，要加括号才能执行）。

属性 property（存数据）

name: "周雨欣"
age: 20
major: "信息管理"

方法 method（做事情）

study()
sayHi()
var student = { name: "周雨欣", // 属性 study: function() { // 方法 return this.name + " 在学习"; } }; student.study(); // ✅ 加括号，得到结果 student.study; // ❌ 没有值，只是一段函数

增、删、改、查

CRUD

点语法既能读也能写：赋值就是新增或修改，delete 用来删掉一个属性。

var book = { ... }
var book = { title: "JavaScript", price: 59 }; book.author = "周雨欣"; // 增 book.price = 49; // 改 delete book.title; // 删 book.author; // 查

方法里的 this

this

方法里的 this 指向"调用它的那个对象"。谁点了这个按钮，this 就是谁。

person.intro() → this.name = ?
var person = { name: "周雨欣", intro: function() { return "我是" + this.name; } }; person.intro(); // "我是周雨欣"

遍历对象

for...in

for...in 把每个 key 轮流取出来，再用 obj[key] 拿到值；Object.keys() 直接拿到所有 key 组成的数组。

var scores = { 语文: 92, 数学: 88, 英语: 95 }
for (var key in scores) { console.log(key, scores[key]); } Object.keys(scores); // ["语文","数学","英语"] Object.values(scores); // [92, 88, 95]

对象是怎么来的：原型链

__proto__

自己身上没有的属性，会沿着原型链一层层往上找：实例 → 构造函数.prototype → Object.prototype → null。 所以一个普通对象才有 toString()、hasOwnProperty() 这些"白送"的方法。

student
name: "周雨欣"
→
Student.prototype
major: "信息管理"

Object.prototype
toString / hasOwnProperty
→
null
student.major; // 自己身上没有 → 去 prototype 找到 student.toString; // 再往上 → Object.prototype 找到 student.notExist; // 一路找不到 → undefined // 判断属性是"自己的"还是"继承来的" student.hasOwnProperty("name"); // true student.hasOwnProperty("major"); // false

对象的常用工具方法

Object.*

Object 是一个"工具箱"对象，里面装着一堆用来操作其他对象的静态方法。

Object.keys()

取所有键名
["name","age","major"]

Object.values()

取所有值
["周雨欣",20,"信息管理"]

Object.entries()

键值对数组
[["name","周雨欣"], …]

Object.assign()

合并对象
{...a, ...b}

Object.freeze()

冻结，禁止修改
改不动了

JSON.stringify()

对象 → 字符串
'{"name":"…"}'
var o = { name: "周雨欣", age: 20 }; Object.keys(o); // ["name", "age"] Object.values(o); // ["周雨欣", 20] Object.entries(o); // [["name","周雨欣"], ["age",20]] Object.assign({}, o, { age: 21 }); // 合并，后面覆盖前面 JSON.stringify(o); // '{"name":"周雨欣","age":20}'
属性是抽屉里的东西，方法是抽屉上的把手 —— this 就是"你正在拉的那个抽屉"。
