JavaScript 的两种定时器

setTimeout 只执行一次  |  setInterval 每隔一段时间重复执行

setTimeout —— 单次定时

只执行一次

等待指定毫秒后执行回调，执行完就结束。clearTimeout(id) 可以在执行前取消。

// 语法 var id = setTimeout(function () { console.log("时间到！"); }, 1000); clearTimeout(id); // 取消
ms
—
点击「执行一次」，开始倒计时
累计触发次数：0　　最近一次触发时间：—

setInterval —— 循环定时

重复执行

每间隔指定毫秒执行一次，一直重复直到调用 clearInterval(id) 停止。

// 语法 var id = setInterval(function () { console.log("每 1 秒执行一次"); }, 1000); clearInterval(id); // 停止循环

两者的区别

记住这张表
对比项 setTimeout setInterval
执行次数 只执行 1 次，执行后自动结束 每隔一段时间执行，无限循环
取消方法 clearTimeout(id) clearInterval(id)
常见用途 延迟提示、防抖、广告 3 秒后关闭 时钟、轮播图、倒计时、轮询接口
如何只跑 N 次 本身只能 1 次 在回调里计数，到次数后 clearInterval
时间精度 都只是"最快等待时间"，回调会进入任务队列排队，实际执行时间 ≥ 设定时间
两种定时器都会返回一个数字 id，用这个 id 才能取消。
