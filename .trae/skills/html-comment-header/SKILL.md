# HTML 注释头规范

在本项目新建任何 HTML 文件时，必须在 `<!DOCTYPE html>` 之后、`<html>` 标签之前插入以下注释块：

```html
<!DOCTYPE html>
<!--
    作者：周雨欣
    建立时间：YYYY-MM-DD
    使用大模型：当前模型名称
    功能名称：该页面的功能描述
-->
<html lang="zh-CN">
```

## 执行规则

1. 建立时间取当天的实际日期，格式 YYYY-MM-DD。
2. 使用大模型填当前会话所用模型的名称（如 Kimi-K3）。
3. 功能名称用简短中文概括页面用途（如"数7游戏"）。
4. 四项信息缺一不可；仅修改已有文件功能时无需重复添加。
5. **提示词记录**：把用户本次任务的原始提示词追加到项目根目录 `zhou_prompt.md`，格式为 `### YYYY-MM-DD ｜ 文件名` 加一行 `> 原始提示词`；文件不存在则先创建。
6. 项目根目录 agents.md 记录了同一规则，两者保持一致。
